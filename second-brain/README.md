# 第二の脳（Claude × Obsidian × LINE）

思いついたことを一言投げるだけで、**自分の言葉で**台本もnoteも書けるようにするための仕組み。
Obsidianが「情報を貯める箱」、Claude Codeが「その箱を読んで考える係」、LINEが「スマホからの入口」です。

```
スマホのLINE ──► Obsidian（Vault）◄── Claude Code
   思いついたら投げる    情報が貯まる箱      読んで書く
```

## このフォルダは何か

Obsidian Vaultにそのまま入れて使う、**第二の脳の完成済みテンプレート**です。
ルールブック（`CLAUDE.md`）・プロフィールの受け皿・フォルダ構成・コピペ用プロンプトが揃っています。

## 使い方

1. **[SETUP.md](SETUP.md) を上から順にやる**（30分ほど）
   - Obsidianを入れる → Vaultを作る → このフォルダの中身をコピー → Claude Codeとつなぐ
   - インタビューに答えて「自分」を覚えさせる
   - LINE連携でスマホからメモを流し込む
2. あとは **`prompts/03_よく使う指示.md`** の言葉を投げるだけ

## 中身

| ファイル / フォルダ | 役割 |
|---|---|
| `CLAUDE.md` | Claudeが必ず従うルール（口調・整理・保存） |
| `プロフィール.md` | 自分の情報。インタビューで埋まる |
| `INDEX.md` | 何がどこにあるかの目次 |
| `SETUP.md` | PC・スマホ側の手順書 |
| `prompts/01_インタビュー.md` | セットアップ用のコピペプロンプト |
| `prompts/02_LINEメモ整理ルール追加.md` | LINE整理ルール（`CLAUDE.md`に導入済み） |
| `prompts/03_よく使う指示.md` | 日々使う言葉のチートシート |
| `台本/` `記事/` `メモ/` | 過去作を入れる場所 |
| `LINE/` | LINEから自動で入る生メモ |
| `LINEメモ整理/` | 仕分け結果（タスク／アイデア／リンク・参考／メモ） |
| `作成物/` | Claudeに作らせたものを残す場所 |

## 育て方（ここが本体）

```
作る ──► 覚えさせる ──► 次はもっと良くなる ──► また覚えさせる
```

普通のAIチャットは忘れますが、第二の脳は**作業した分だけ積み上がります**。

- 最初に入れる過去作は「**自分が納得できているもの**」を選ぶ（入れたレベルが基準になる）
- 作ったものは `この台本も保存して` の一言で残す
- LINEメモの整理は**週1回で十分**。貯めっぱなしでも消えない
