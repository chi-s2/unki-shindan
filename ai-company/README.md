# AI社員だけで回す会社（ちほ版）

「AI社員だけで会社を作る」のやり方を、**ちほさんが今動かしている事業**に当てはめて組んだ一式です。
動画の例は地域店舗向けのAI自動化サポート会社でしたが、ここは
**note教材 → オンライン秘書講座 → 伴走サポート → AI活用コミュニティ** の事業に置き換えてあります。

## 今日やる3つ

1. `01-concept.md` を読んで、〔要決定〕の欄（講座の受講料・開講日）を埋める
2. `03-prompts/00-common.md` の枠をコピーして、いつも使っているAIに1回貼る
3. `demo/index.html` をブラウザで開いて、自分で1本作ってみる

## AIの使い分け（要点だけ）

- **GPT5.6**＝社長。決める仕事（順番・価格・やめること）
- **GPT work**＝実務。表・数字・チェックリスト
- **Claude fable5**＝設計と文章。原稿・資料・デモの中身

呼び方は動画に合わせています。画面のメニュー名が違うときは、同じ役割のAIに置き換えてください。

## 公開するときの注意

- `lp/` と `demo/` は、そのままGitHub Pagesで公開できます（サーバー不要）。
  URLは `https://<ユーザー名>.github.io/unki-shindan/ai-company/lp/` の形になります。
- **Pagesを有効にすると、このフォルダの中身は全部だれでも見られます。**
  `data/` のCSVに本物の顧客名・金額・連絡先は入れないでください。
  実データを扱うなら、Googleスプレッドシートか非公開リポジトリに移すこと。
- LPのLINEボタンは `href="#"` のままです。友だち追加URLに差し替えるまで動きません。
- 公開の前に、必ず `07-prepublish-checklist.md` を通してください。

## 大事な前提

作成・調査・整理はAIに任せていい。
ただし**公開前の事実確認、料金と約束の範囲、法律とお金まわり、最終判断は人間がやる**。
ここを飛ばすと、AIが作った便利な文章がそのまま事故になります。
