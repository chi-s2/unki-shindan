# あなたの商品は動画で売れるか診断（TikTok Shop）

TikTok Shopの記事「1週間で33.4億円。今から参入するためのTikTok Shop完全攻略本」を
診断ページにしたもの。1ファイル完結（`index.html`）で、外部依存はGoogle Fontsのみ。

公開URL（GitHub Pagesを有効にした場合）: `https://chi-s2.github.io/unki-shindan/tiktok-shop/`

## 診断のしくみ

全10問・4段階回答（そう思う=3点 → 思わない=0点）。
記事の「変化が見える商品」という考え方を、変化の見せ方3軸に分解している。

| 軸 | 質問 | 結果タイプ | 該当しやすい商材 |
|---|---|---|---|
| `look` | Q1〜3 | ビフォーアフター型（見た目が変わる） | 美容・アパレル |
| `work` | Q4〜6 | 実演・時短型（手間が変わる） | 日用品・機能商材・BtoB |
| `story` | Q7〜10 | ストーリー型（意味が変わる） | 食品・こだわり商材 |

軸ごとに質問数が違う（3/3/4問）ので、**満点比で正規化してから比較**する。
結果画面では1位（主軸）だけでなく2位・3位も出して、次に使える型がわかるようにしている。

同点のときは `look → work → story` の順で上位を採用する。

## 差し替える場所

`index.html` の `<script>` 内、冒頭のこの2行だけ。

```js
var LINE_URL = "";   // 公式LINEのURLを入れるとボタンが出る。空ならボタンなしで案内文だけ
var LINE_MSG = "動画の型が決まったら、<br>あとは撮って出すだけです。";
```

- LINE内ブラウザで使うなら `LINE_URL` は空のままでよい（すでにLINE内にいるため）
- 計測する場合は `<head>` の `var GA_ID = "";` にGA4の測定ID（`G-` から始まる）を入れる
  - 取るイベントは `page_view` / `diagnosis_start` / `diagnosis_complete` の3つ

質問文・結果文を変えるときは `QUESTIONS` と `RESULTS` を編集する。
質問を増減しても正規化が効くので、軸ごとの問数が揃っていなくても判定は壊れない。

## 掲載している数字の出典

- 週間流通総額 33.42億円 / 平均販売価格 2,643円（前週比 +18.8%）
  … Kalodata Japan ウィークリーレポート（2026年7月8日発表／対象週 2026年6月29日〜7月5日）
- コンテンツ起点の購入 約70%、王子製薬・OKARATの事例
  … TikTok ニュースリリース（2026年2月3日／2025年6月30日〜12月末の実績）

数字を更新するときは、トップ画面の `.stat-card` と、結果画面の `RESULTS` 内の記述の
両方を直す（同じ数字が2箇所に出る）。

## 動作確認済み

- 全10問がタップで最後まで進み、3タイプすべての結果が表示される
- 回答の全パターン（4^10 = 1,048,576通り）で必ずいずれかのタイプが出る
- iPhone幅（390px）で横スクロールが発生しない
- 回答データは端末内で完結し、どこにも送信・保存されない
