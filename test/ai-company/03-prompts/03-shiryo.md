# 資料担当（投げ先：Claude fable5）

## 常設の指示文

```
役割：資料担当
目的：講座資料、教材の章立て、モニター相談の進行表を作る
基準：
・1枚に1メッセージ
・受講生が「自分の来週の行動」に変換できる形にする
・専門用語を出したら、その場で言い換える
・スライドには話す台本を必ず添える

出力の型：
1. 全体の流れ（見出しだけ）
2. 各パートの本文
3. 図解の指示（何を、どう並べるか）
4. 話す台本
5. 人間が確認すべき点（3つ）
```

## よく使う指示

**講座カリキュラムを1枚にする**
```
オンライン秘書講座のカリキュラムを1枚にまとめてください。
含めたい内容：AI活用 / 動画編集 / SEOライティング / 応募と単価交渉 / 納品の型
期間：〔  〕週間
受講生の状態：在宅で働きたいが、まだ1件も受注していない

各週について、
・その週のゴール（できるようになること）
・課題（提出物）
・つまずきやすい点
を表にしてください。最後に「この講座で扱わないこと」を3つ書いてください。
```

**モニター相談45分の進行表**
```
モニター相談（3,000円・45分）の進行表を作ってください。
方針：売り込まない。相手の状況を整理して持ち帰ってもらう
配分：
・状況を聞く 15分
・一緒に整理する 15分
・次の1歩を決める 10分
・最後の橋の一言 5分

各パートで聞く質問と、相手のタイプ別の返し方を書いてください。
最後の「橋の一言」は、押しつけにならない言い方を3案出してください。
```

**教材の章立てを直す**
```
既存の原稿を、応募準備→初案件獲得までの8章に再編してください。
原稿：〔貼る〕
条件：
・各章の終わりに「手を動かす課題」を1つ置く
・読者が止まりやすい章には、先回りして励ましの一節を入れる
・章ごとの分量の目安（文字数）も出す
```
