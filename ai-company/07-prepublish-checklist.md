# 07 公開前チェックリスト

AIが作ったものは便利だけど、**間違い・誇張・古い情報・危ない表現**が混ざる。
公開・送信・納品の前に、ここを必ず通す。人間がやる。

---

## 事実

- [ ] 価格・期間・定員が、今決まっているものと一致している
- [ ] 実績の数字に根拠がある（人数・件数・金額）
- [ ] 引用したツール名・サービス名・仕様が今も正しい
- [ ] 日付（開講日・締切）が過去になっていない

## 表現

- [ ] 「稼げる」「必ず」「保証」「誰でも」が入っていない
- [ ] 平均収入・再現性をうたっていない
- [ ] 他社・他人を落として自分を上げていない
- [ ] 不安をあおって決めさせる作りになっていない

## 提供範囲

- [ ] まだ無いものを「あります」と書いていない
- [ ] サポートの範囲（回数・期間・返信の速さ）が明記されている
- [ ] 返金・キャンセルの扱いが書いてある（有料商品の場合）
- [ ] 対応できない相談を、事前に断ってある

## 個人情報・秘密

- [ ] 受講生やクライアントの名前・写真を、許可なく載せていない
- [ ] APIキー・パスワード・内部メモがコードやPDFに残っていない
- [ ] スクリーンショットにメールアドレスや金額が写り込んでいない
- [ ] 送信先のアドレス・宛名が合っている

## 読みやすさ・導線

- [ ] 初めて読む人が、3秒で「誰向けか」分かる
- [ ] 申し込み・登録の場所が1つに絞られている
- [ ] スマホで見て崩れていない
- [ ] リンクが全部開く

## 専門家に回すもの（自分で判断しない）

- 特定商取引法の表記、返金規定の文面
- 税務・確定申告に関する具体的な助言
- 契約書、業務委託の条件
- 医療・健康・投資に関わる表現

---

## AIに投げるチェック用プロンプト

```
以下の成果物を公開前にチェックしてください。

観点：
・事実と違う内容がないか
・誇大表現がないか
・提供できない約束をしていないか
・個人情報や内部情報が含まれていないか
・初めて読む人に分かるか
・申し込み導線が1つに絞れているか

問題点は「箇所 → なぜ危ないか → 修正案」の3点セットで出してください。
問題がない場合も「ここは判断が分かれる」という箇所を3つ挙げてください。

成果物：
〔貼る〕
```

**注意**：AIのチェックは下読み。最終判断は必ず人間がする。
