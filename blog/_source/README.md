# サイトの運用手順

このサイトは `_source/` の中身から自動で組み立てています。
HTMLを直接さわる必要はありません。**直すのは `_source/` の中だけ**です。

```
blog/
├── _source/          ← ここだけ編集する
│   ├── config.json   会社情報・事業内容・会社概要
│   ├── posts/*.md    ブログ記事（1記事＝1ファイル）
│   ├── build.py      HTMLを組み立てる
│   └── make-images.js アイキャッチ画像をつくる
│
├── index.html        ↓ ここから下は build.py が自動生成する
├── services.html        （直接編集しても次回の生成で消えます）
├── company.html
├── blog.html
├── articles/*.html
│
├── about.html        ← この3つは手書き。直接編集してOK
├── contact.html
├── privacy.html
└── css/style.css     ← デザイン。直接編集してOK
```

---

## 1. 記事を1本追加する

### 手順

1. `_source/posts/` に `.md` ファイルを新しく作る
   ファイル名がそのままURLになります（例：`ai-tool-hikaku.md` → `articles/ai-tool-hikaku.html`）
2. 下のテンプレートを貼って中身を書く
3. ターミナルで `blog/` に移動して、次の2つを実行する

```bash
node _source/make-images.js   # アイキャッチ画像をつくる
python3 _source/build.py      # HTMLを組み立てる
```

これで記事ページが増え、ブログ一覧とトップページにも自動で並びます。

### 記事テンプレート

```markdown
title: 記事のタイトル｜サブタイトル
description: 検索結果とSNSに出る説明文。120文字くらいまで。
category: AI副業
tags: AI副業, 始め方
date: 2026.09.05
eyecatchTitle: アイキャッチに<br>入れる文字<em>ここは色が変わる</em>
eyecatchSub: アイキャッチの小さい文字
---

導入の文章をここに書く。

## 見出し

段落。**強調したい言葉**はアスタリスク2つで囲む。
[リンクの文字](https://example.com) はこの書き方。

### 小見出し

- 箇条書き
- 箇条書き

1. 番号つき
2. 番号つき

:::point ポイント枠のラベル
枠の中に入れたい文章。
:::

:::ad 広告リンク設置枠：クラウドソーシング無料登録
```

### 使える書き方

| 書き方 | 表示 |
|---|---|
| `## 文字` | 大見出し（ピンクの丸つき） |
| `### 文字` | 小見出し（ゴールドの線つき） |
| `**文字**` | ピンクの太字 |
| `[文字](URL)` | リンク |
| `- 文字` | 箇条書き |
| `1. 文字` | 番号つきリスト |
| `:::point ラベル` 〜 `:::` | ピンクのポイント枠 |
| `:::ad ラベル` | 広告リンクを置く枠 |

## 2. 会社の情報を変える

`_source/config.json` を直して `python3 _source/build.py` を実行するだけです。
**全ページにまとめて反映されます。**

| 直す場所 | 変わるもの |
|---|---|
| `company` | 社名（全ページのヘッダー・フッター・タイトル） |
| `tagline` | ヘッダーのキャッチコピー |
| `siteUrl` | SNSシェア用のURL。**公開先が決まったら必ず直す** |
| `hero` | トップページの大きな見出しまわり |
| `services` | 事業内容（トップと事業内容ページの両方） |
| `flow` | 依頼から納品までの流れ |
| `profile` | 会社概要の表 |
| `values` | 会社概要の「大事にしていること」 |

### 会社概要の表について

`profile` は `["項目名", "中身", "注意書き"]` の3つ組です。
3つ目に文字を入れると、ベージュの「※ご記入ください」バッジが出ます。
**設立日と所在地は空のままにしてあります。** 正しい情報を入れて、3つ目は空文字にしてください。

```json
["設立", "2024年4月", ""]
```

## 3. 広告リンクを差し替える

記事の中の `:::ad ...` は、いまは枠だけの状態です。
提携が通ったら、その行を広告タグに置き換えてください。HTMLをそのまま書けます。

```markdown
<div class="affiliate-slot"><a href="ここに広告URL">サービス名を見る</a></div>
```

---

## 4. 公開する

GitHub Pages で公開する場合、`blog/` の中身をそのまま置けば動きます。
ビルドの仕組みは不要です（生成済みのHTMLを置くだけ）。

公開したら `config.json` の `siteUrl` を実際のURLに直して、
もう一度 `python3 _source/build.py` を実行してください。
SNSでシェアしたときの画像とURLが正しくなります。

---

## 困ったとき

- **`python3 _source/build.py` でエラーが出る**
  `config.json` のカンマや括弧が足りていないことが多いです。エラーの行番号を見てください。
- **記事が一覧に出てこない**
  `.md` ファイルの1行目から `---` までの間に `title` と `date` があるか確認してください。
- **アイキャッチが出ない**
  `node _source/make-images.js` を先に実行し忘れていないか確認してください。
