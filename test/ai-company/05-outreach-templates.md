# 05 声のかけ方テンプレ

売り込み感を弱めることを最優先にする。**押した瞬間に読まれなくなる。**

---

## 1. Threadsからの橋（投稿の最後の一言）

- 「同じところで止まってた人向けに、順番だけまとめたものがあります。いる人だけどうぞ」
- 「これ、聞かれることが多いので1枚にしました。プロフィールに置いてあります」
- 「続きは長くなるので、テンプレの形にしてあります」

避ける言い方：「今すぐ登録」「限定」「見ないと損」

## 2. LINE登録直後（1通目の冒頭）

```
登録ありがとうございます。ちほです。

わたしは元公務員で、税務事務を7年やっていました。
辞めてから半年、在宅の仕事を「調べるだけ」で終わらせていた人間です。

このLINEでは、その半年でやらなくてよかったことと、
やっておけばよかったことを順番にお送りします。

まず1つだけ聞かせてください。
今いちばん困っているのは、次のどれですか？
1 何を売ればいいか分からない
2 応募文が書けない
3 時間が取れない

番号だけで大丈夫です。
```

## 3. モニター相談への案内（教材の巻末・LINE）

```
教材を読んで「自分の場合はどうなんだろう」と思ったら、
45分だけ話す時間を作っています（3,000円）。

売り込みはしません。
その場で状況を整理して、次の1歩を決めて終わりです。
講座の案内は、こちらから聞かれたときだけします。
```

## 4. 相談の最後の「橋の一言」（伴走サポートへ）

- 「1人で進めてみて、3週間たっても止まってたらまた声をかけてください」
- 「毎週見てほしい、というやり方もあります。今日は説明しないでおきますね」
- 「必要になったら伴走という形もあります。今は要らないと思います」

## 5. クライアントワークの営業DM（診断ページ・動画編集）

3パターン。相手を見たことが伝わる書き出しにする。

**A：改善案を1つ持っていく**
```
突然のご連絡失礼します。〔　〕を拝見しました。
〔具体的に見た箇所〕がとても分かりやすくて、参考にさせていただきました。

1点だけ、〔　〕のところで、
読んだ人が次に何をすればいいか迷いそうだと感じました。

もしよければ、その部分だけの改善案を1つ、無料でお送りします。
不要でしたらこのままご放念ください。
```

**B：見本を先に見せる**
```
はじめまして。〔　〕を作っている〔　〕と申します。

〔相手の事業〕向けに、〔　〕診断のページを試しに1つ作ってみました。
サンプルはこちらです：〔URL〕

売り込みではなくて、こういうものが作れます、という見本です。
使えそうなら、そのままお渡しします。
```

**C：やり取りの続き（返信があった後）**
```
ありがとうございます。
ご希望を伺ってから見積もりを出したいので、3つだけ教えてください。

1 このページを見た人に、次にしてほしいこと
2 いつまでに公開したいか
3 用意できる文章や写真があるか

これが分かれば、金額と日数をお出しします。
```
