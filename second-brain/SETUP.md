# セットアップ手順（PC側でやること）

このフォルダの中身はすでに完成しています。
残っているのは、**自分のPCとスマホでの準備**だけです。上から順にやれば30分ほどで動きます。

- STEP 1〜4 … Claude × Obsidian（第二の脳の土台）
- STEP 5 … インタビューで「自分」を覚えさせる
- STEP 6 … LINE連携（スマホからメモを流し込む）

---

## STEP 1. Obsidianを入れる

1. [Obsidian公式サイト](https://obsidian.md/) を開く
2. 自分のPCに合った版をダウンロード（Mac → macOS版／Windows → Windows版）
3. Macの場合、ダウンロードした `Obsidian-x.x.x.dmg` を開き、Obsidianのアイコンを右側のApplicationsフォルダへドラッグ
4. Launchpad（またはアプリ一覧）からObsidianを起動

無料です。課金は不要です。

## STEP 2. Vault（保管庫）を作る

1. Obsidianを起動すると最初にフォルダ選択の画面が出る
2. 「保管庫を新規作成する」の **作成** を選ぶ
3. 名前を入力（例：`Obsidian_Vault`）
4. 保存場所を選ぶ → **デスクトップなど、自分がすぐ見つけられる場所**にする
5. **作成** をクリック

> Vault ＝ メモを貯めておく箱。ここに入れたものが第二の脳の中身になります。

## STEP 3. このフォルダの中身をVaultに入れる

作ったVaultの中に、この `second-brain/` フォルダの中身を**まるごとコピー**します。

```bash
# 例：デスクトップに Obsidian_Vault を作った場合（Mac）
cp -R second-brain/* ~/Desktop/Obsidian_Vault/
```

GitHubからZipでダウンロードした場合は、解凍した `second-brain` の中身をVaultフォルダへドラッグでもOKです。

コピー後、Vaultの中はこうなります：

```
Obsidian_Vault/
├── CLAUDE.md          ← Claudeが必ず読むルールブック
├── プロフィール.md      ← 自分の情報（STEP 5で埋まる）
├── INDEX.md           ← 目次
├── SETUP.md           ← この手順書
├── prompts/           ← コピペ用プロンプト集
├── 台本/  記事/  メモ/  ← 過去作を入れる場所
├── LINE/              ← LINEメモが自動で入る場所
├── LINEメモ整理/        ← 仕分け結果が入る場所
└── 作成物/             ← Claudeに作らせたものを残す場所
```

## STEP 4. Claude Codeとつなぐ

1. [Claudeのダウンロードページ](https://claude.com/download) からデスクトップ版をダウンロード
   （Macは `Claude.dmg` を開いて、アイコンをApplicationsへドラッグ）
2. Claudeデスクトップ版を起動し、**画面左上の「Code」** を選択
3. チャット入力欄の上にある**フォルダのマーク**をクリック
4. STEP 2で作った **Vaultフォルダ** を選んで「開く」
5. チャット画面にそのフォルダ名が表示されれば連携完了

> APIキーもアカウント連携も不要です。「Claudeの作業場所をObsidianのフォルダに指定する」だけ。
> これでClaudeがVaultの中を読み書きできるようになります。

---

## STEP 5. インタビューで「自分」を覚えさせる

1. `prompts/01_インタビュー.md` を開く
2. `---` から下を全部コピーして、Claude Codeに送る
3. 質問に1問ずつ答えていく（全28問＋自由記述）

答え終わると `プロフィール.md` が埋まり、`CLAUDE.md` の口調設定も更新されます。

### ここが一番の分かれ道

- **見栄を張らない。遠慮して一言で済ませない。**
- 少し恥ずかしいことでも正直に書くほど、出てくる文章が自分の言葉に近づきます
- 誰かに見られるものではないので、時間をかけて答えてください

### 過去作を入れる

インタビューが終わったら、過去の資産をどんどん入れます。

```
今から過去のインスタの台本を送るので、全部 台本/ に保存してください
```

と送ってから、台本を一気に貼り付ける。**何のデータを送るのか先に伝える**のがコツです。

- 過去のSNS投稿 → `台本/`
- note記事 → `記事/`
- 気になった記事・自分用メモ → `メモ/`

入れ終わったら `整理して` と送れば、分類され `INDEX.md` に目次ができます。

### 試してみる

```
インスタのリール台本を作って、テーマは〇〇で
```

説明ゼロで自分の書き方・考え方を踏まえたものが返ってきたら成功です。

## STEP 6. LINE連携（スマホから流し込む）

思いついた瞬間のメモを、LINEに投げるだけでVaultに貯まるようにします。
※ STEP 5がまだでも、ここだけ先にやってもOKです。

### 6-1. コミュニティプラグインを有効にする

1. Obsidian左下の**歯車アイコン**から設定を開く
2. 左メニューの **コミュニティプラグイン** を選ぶ
3. 「コミュニティプラグインを有効化」ボタンが出ていたら押す（制限モードの解除）

> Obsidianの安全装置なので、押しても壊れないし課金もありません。

### 6-2. LINE Notes Sync をインストール

1. コミュニティプラグインの **閲覧** を押す
2. 検索バーに `LINE Notes Sync` と入力
3. **インストール** → 終わったら **有効化**（この2段階）

### 6-3. LINEで友だち追加

1. 設定画面のプラグイン一覧から「LINE Notes Sync」を開く
2. 表示されたQRコードをスマホのLINEで読み取り、公式アカウントを友だち追加

### 6-4. 自分のIDを取得

1. 追加したアカウントのトークで「テスト」など何でもいいので送信
2. 自動返信で **LINE User ID**（英数字の長い1行）が返ってくる → コピー
3. 忘れたら `/myid` と送ればいつでも確認できます

### 6-5. Obsidianに登録

Obsidianの設定画面（LINE Notes Sync）で3つ入力：

| 項目 | 入れる値 |
|---|---|
| Note folder path | `LINE`（このVaultならこれ。無いフォルダ名でも自動で作られます） |
| Vault ID | 自分で決める合言葉（例：`my-vault`） |
| LINE User ID | 6-4でコピーしたID |

入力したら下にスクロールして **Register** を押す。成功メッセージが出れば連携完了。

> よくある失敗：コピペしたIDの**前後に空白が紛れ込んでいる**。うまくいかないときはまずここを疑う。

### 6-6. 自動同期をオンにする（必須）

同じ設定画面で：

- **Auto sync** → オン（設定した間隔で自動的に取り込む）
- **Sync on startup** → オン（Obsidian起動時にも取り込む）

これをオフのままだと、サイドバーの同期ボタンを手で押した時しか入ってきません。

> Obsidianを閉じている間に送ったメモも消えません。暗号化されて待機し、次の同期でまとめて入ります。

### 6-7. テスト

LINEで「テスト」と送る → Obsidianの `LINE/` フォルダに日付名のファイルができていれば成功。
すぐ確認したいときは、サイドバーの同期ボタンを押す。

### 保存のされ方（3パターン）

設定画面の「ファイル整理設定」で選べます。**迷ったらデフォルトのままでOK**（あとから変更可）。

| 設定 | 動き | 向いている人 |
|---|---|---|
| デフォルト | 1メッセージ＝1ファイル | まずはこれ |
| Organize by date | 日付ごとのフォルダに振り分け | メモが増えてきたら |
| Group messages by date | 1日分を1ファイルにまとめる | デイリーノート派 |

### 6-8. メモを仕分けする

`CLAUDE.md` にルールが入っているので、貯まったら一言：

```
LINEメモを整理して
```

`LINEメモ整理/` に日付ファイルができて、**タスク／アイデア／リンク・参考／メモ**の4つに仕分けされます。
仕分けたアイデアは、以後の台本づくりのネタ帳としてClaudeが自動で見にいきます。

## うまくいかない時は

| 症状 | 対処 |
|---|---|
| メモが入ってこない | LINE User ID と Vault ID を見直す。**コピペ時の前後の空白**が最多の原因 |
| 検索してもプラグインが出ない | Obsidian本体が古い。アップデートしてから再検索 |
| 「メッセージが読み込まれませんでした」 | プラグインを最新版に更新し、Obsidianを再起動 |
| IDが分からなくなった | LINEで `/myid` と送る |
| Claudeがプロフィールを読んでいない気がする | Claude CodeでVaultフォルダが開かれているか確認。`CLAUDE.md` がVault直下にあるか確認 |

## 注意事項

- 画像の送信は無料プランだと**累計10枚まで**（テキストは無制限なのでメモ用途なら無料で足ります）。写真も多用したい人向けに有料プランあり
- メッセージは暗号化されますが、**パスワードや口座情報のような重要情報は送らない**習慣にしておく
