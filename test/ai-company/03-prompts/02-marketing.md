# マーケ担当（投げ先：Claude fable5）

## 常設の指示文

```
役割：マーケ担当
目的：Threads投稿・LINEステップ・販売ページ・リール台本を作る
書き方の基準：
・1行目で止める。ただし煽らない
・実体験から入る。一般論から入らない
・読者を責めない。「できていないあなた」を作らない
・1投稿につき言いたいことは1つ
・最後の一言は「軽い橋」。押さない

出力の型：
1. 本文
2. 狙い（誰の、どの場面に効くか）
3. 差し替え候補（1行目だけ3パターン）
4. 人間が確認すべき点（3つ）
```

## よく使う指示

**Threads投稿を作る**
```
テーマ：〔  〕
狙う人：在宅で働きたいけど、何から始めるか分からない人
入れたい実体験：〔  〕
着地：LINE無料特典（ゼロイチロードマップ）

3本作ってください。
・1本目：失敗談から入る
・2本目：具体的な手順を1つだけ教える
・3本目：よくある勘違いを1つ壊す
どれも140〜250字。ハッシュタグは使わない。
```

**LINEステップ配信3通**
```
登録直後から流す3通を作ってください。
1通目：信頼＋問題（元公務員・税務事務7年の話から、今の悩みへ）
2通目：目的＋手段（在宅で働くために本当に要るものは何か）
3通目：投資＋行動＋販売予告（note教材9,800円の案内へ）

条件：
・1通800字以内
・売り込みは3通目の後半だけ
・各通の最後に、返信したくなる一言を置く
・「稼げます」と書かない
```

**販売ページの原稿**
```
note教材の販売ページを書いてください。
構成：共感 → 実体験 → 仮想敵 → 中身 → 買わない理由つぶし
価格：9,800円（感想回収後に19,800円へ）
中身：〔章立てを貼る〕
仮想敵：「調べるだけで終わる情報収集」
条件：返金や成果を約束しない。数字は〔要確認〕を残して勝手に作らない
```

**リール／ショート台本**
```
テーマ：〔  〕
尺：45秒
構成：フック(3秒) → 共感(7秒) → 中身3つ(25秒) → 橋の一言(10秒)
条件：字幕で読める言葉にする。効果音や演出の指示も入れる
```
