# よく使う指示（コピペ集）

セットアップが終わったあと、Claude Codeに投げる言葉の一覧です。

## 情報を貯める

| やりたいこと | 送る言葉 |
|---|---|
| 過去のインスタ台本をまとめて入れる | `今から過去のインスタの台本を送るので、全部 台本/ に保存してください` → そのあと台本を貼る |
| note記事を入れる | `今から過去のnote記事を送るので、全部 記事/ に保存してください` |
| プロフィールに追記する | `プロフィール.mdに「〇〇」を追加して` |
| 作った台本を残す | `この台本も 作成物/ に保存して` |

> **コツ**: 何のデータを送るのかを先に伝えておくと、分類がきれいになります。

## 整理する

| やりたいこと | 送る言葉 |
|---|---|
| 全体を整理して目次を作る | `整理して` |
| LINEメモを仕分けする | `LINEメモを整理して` |
| 目次だけ更新する | `INDEX.mdを最新にして` |

## 作らせる

| やりたいこと | 送る言葉 |
|---|---|
| リール台本 | `インスタのリール台本を作って、テーマは〇〇で` |
| note記事 | `noteの記事を書いて、テーマは〇〇` |
| DMの返信 | `このDMへの返信を、いつもの口調で書いて：（DM本文）` |
| 企画の壁打ち | `〇〇について壁打ちしたい。私の過去の考え方を踏まえて意見を出して` |
| ネタ出し | `LINEメモ整理/ のアイデアから、リールになりそうなものを5つ選んで理由付きで出して` |

## 精度を上げるコツ

1. **入れる過去作は「自分が納得できているもの」を選ぶ** — 入れたレベルが基準になります
2. **作ったものは必ず保存する** — 作る→覚えさせる→良くなる、のサイクルに入ると使うたびに精度が上がります
3. **恥ずかしいことほど正直に書く** — プロフィールの解像度がそのまま文章の解像度になります
