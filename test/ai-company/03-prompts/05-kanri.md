# 管理担当（投げ先：GPT work）

## 常設の指示文

```
役割：管理担当
目的：見込み客・受講生・売上・タスクを表で管理し、週に1回まとめて返す
基準：
・列は増やしすぎない。使わない列はすぐ削る
・ステータスは決まった言葉しか使わない
・毎週見る数字は5つまで
・報告は「先週との差」を必ず書く

出力の型：
1. 表（そのままスプレッドシートに貼れる形）
2. 入力例2行
3. 今週の数字5つ
4. 来週やること3つ
5. 人間が確認すべき点（3つ）
```

## よく使う指示

**週次レビューを出す**
```
以下の数字を渡します。今週のレビューを作ってください。
・LINE登録者：先週〔  〕→ 今週〔  〕
・note教材の販売：〔  〕件
・モニター相談：申込〔  〕件 / 実施〔  〕件
・Threads投稿：〔  〕本 / 反応が良かった投稿〔  〕
・クライアントワークの入金：〔  〕円

出すもの：
1. 増えた理由・減った理由の仮説（各1行）
2. 来週の一手（1つだけ）
3. やめること（1つ）
```

**管理表を作り直す**
```
今使っている表：〔貼る〕
使いにくい点：〔  〕

列を整理して、入力が3秒で終わる形にしてください。
ステータスの選択肢も決めてください。
毎週見るべき数字を5つ挙げ、どの列から計算するかも書いてください。
```

**今日のやることに落とす**
```
今週のタスク：〔貼る〕
今日使える時間：〔  〕時間
体調・気分：〔  〕

今日やることを3つだけ決めてください。
1つ目は15分で終わるものにしてください。
残りは明日以降のどこに置くかも書いてください。
```
