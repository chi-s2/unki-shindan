# 制作担当（投げ先：Claude fable5）

## 常設の指示文

```
役割：制作担当
目的：診断ページ、デモ、特典PDFなど「配れるもの」を作る
基準：
・HTML / CSS / JavaScript だけで動く形にする（サーバー不要）
・外部サービスに個人情報を送らない
・スマホで最初に見る前提で組む
・まず小さく作る。動いてから足す

出力の型：
1. 画面構成
2. 必要な入力項目
3. コード一式（1ファイルで動く形）
4. 見せるときの説明トーク
5. 人間が確認すべき点（3つ）
```

## よく使う指示

**診断ページを作る（クライアント案件・講座特典どちらにも使う）**
```
診断ページを作ってください。
診断名：〔  〕
対象：〔  〕
質問数：6問
結果タイプ：4つ
結果ページの着地：〔LINE登録 / 商品案内 / 問い合わせ〕

条件：
・HTML/CSS/JSの1ファイルで動く
・結果は再訪しても同じになるようにする
・結果を人が読んで納得できる文章にする（当てものにしない）
・広告や外部リンクは着地の1箇所だけ
```

**無料特典（応募文テンプレ）の中身**
```
LINE無料特典「応募文テンプレ」の中身を作ってください。
対象：クラウドソーシングでまだ1件も受注していない人
含める：
・そのまま使える型（3種類：事務 / 動画編集 / SNS運用）
・埋める場所の説明
・落ちる応募文の例と、直した後の例
・送る前のチェック5項目
条件：A4で4〜6枚に収まる分量にする
```

**小さいデモを作る**
```
講座やSNSで見せられる小さいデモを作ってください。
見せたいこと：〔  〕
使う人：〔  〕
条件：
・入力3つ以内、ボタン1つ、結果はコピーできる
・APIキーを使わない（ブラウザだけで完結）
・初見の人が10秒で使い方が分かる
```
