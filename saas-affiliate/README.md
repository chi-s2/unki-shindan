## 守るルール

- 案件の数字（報酬率・継続期間・解約率・Cookie期間）は、ASP管理画面か担当者の回答で確認したものだけを使う。Claudeが出した数字は全部推定
- 価格表は公式サイトで照合するまで公開しない（`draft: true` のまま）
- 開示文は全記事の冒頭に入れる
- 「the best」「guaranteed」などの断定表現は使わない
- 時事表現（"2026 latest" / "this month"）は入れない。stock型で書く

## 撤退ライン

- 3ヶ月連続で自分経由の解約率15%超 → その案件のリンクを差し替え
- 報酬率が半分以下に改定 → 同カテゴリの別ASPへ移行
- 12ヶ月経って月1万円未満 → 継続するか見直す（本業に戻す判断を優先）
